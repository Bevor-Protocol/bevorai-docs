# From code to a living security record

At launch, a Bevor workflow will follow four stages:

<Steps>
  <Step title="Connect a project">
    Create a project and connect its source through the Dashboard, CLI, SDK, API, or CI/CD.
  </Step>
  <Step title="Build the graph">
    Bevor turns code entities and their semantic relationships into a project graph that preserves context across versions.
  </Step>
  <Step title="Surface and validate findings">
    Combine frontier AI security tools, static analyzers, specialist agents, and human review in one analysis record.
  </Step>
  <Step title="Remediate and verify">
    Connect fixes to findings, re-analyze the affected graph, and track residual risk over time.
  </Step>
</Steps>
