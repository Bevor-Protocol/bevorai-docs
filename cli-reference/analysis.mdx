Manage analyses.

## `create`

Create a root analysis for the configured code version.

```bash
bevor analysis create [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--name` | text | No |  | Optional analysis name. |
| `--collision` | choice | No | surface | What Bevor should do if analysis already exists for the given code |
| `--yes, -y` | boolean | No |  | Skip confirmation of action. |
| `--json` | boolean | No |  | JSON output |
| `--force` | boolean | No |  | Skip checks. Not recommended. |

## `use`

Point `.bevor` at an analysis container

```bash
bevor analysis use [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `analysis_id` | text | Yes |  | Analysis container id. |

## `set`

```bash

```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `version_id` | text | Yes |  | Analysis version id to set as HEAD. |


| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--version` | text | No |  | Act on this analysis version id instead of the configured analysis head. |

## `list`

List analyses for the active project.

Examples:

  bevor analyses list
  bevor analyses list -j | jq '.[].id'

```bash
bevor analysis list [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--page` | integer | No |  | Page number to use for resource that supports pagination |
| `--page-size` | integer | No |  | Page size to use for resource that supports pagination |
| `--order` | choice | No |  | How to order results when a resource supports pagination |
| `--order-by` | choice | No |  | What field to order results by when a resource supports pagination |
| `--project, -p` | text | No |  | Project ID (defaults to .bevor config). |
| `--user` | text | No |  | Analysis creator to filter by |
| `--is-owner` | boolean | No |  | Analysis filter by owner only |
| `--json` | boolean | No |  | JSON output |
| `--all, -a` | boolean | No |  | List analyses for all projects in current team |

## `delete`

Delete an analysis container or version.

### `full`

Delete the entire analysis container configured in `.bevor`.

```bash
bevor analysis delete full [OPTIONS]
```

### `version`

Delete a single analysis version (leaf).

```bash
bevor analysis delete version [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `version` | text | No |  | Version id to delete (default: configured analysis head). |
