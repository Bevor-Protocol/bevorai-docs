title: "chat"
---

Manage analysis chats.

## `list`

List chats. Uses the currently configured project, or --project

```bash
bevor chat list [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--page` | integer | Yes |  | Page number to use for resource that supports pagination |
| `--page-size` | integer | Yes |  | Page size to use for resource that supports pagination |
| `--order` | choice | Yes |  | How to order results when a resource supports pagination |
| `--order-by` | choice | Yes |  | What field to order results by when a resource supports pagination |
| `--project` | text | Yes |  | project to list chats for |
| `--json` | boolean | No |  | JSON output |

## `get`

Get the details of a chat.

```bash
bevor chat get [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `chat_id` | text | Yes |  | Chat ID. |
| `--json` | boolean | No |  | JSON output |

## `messages`

Get chat messages for a chat.

```bash
bevor chat messages [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `chat_id` | text | Yes |  | Chat ID. |
| `--json` | boolean | No |  | JSON output |

## `new`

Create a chat thread and open the streaming terminal session. The mode determines if you want
to chat with just code, or with analysis + code. Either use your current configuration.

```bash
bevor chat new [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `mode` | choice | Yes |  | whether to create a chat with analysis or code |

## `resume`

Open the streaming session for an existing thread.

```bash
bevor chat resume [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `chat_id` | text | Yes |  | Thread id (`bevor chat list --json`, field id). |
