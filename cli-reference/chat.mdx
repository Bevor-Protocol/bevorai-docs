---
title: "chat"
---

Manage analysis chats.

## `list`



```bash
bevor chat list [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--page-size, -n` | integer | No | 20 | Results per page. |
| `--json` | boolean | No |  | JSON output |

## `get`



```bash
bevor chat get [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `chat_id` | text | Yes |  | Chat ID. |
| `--json` | boolean | No |  | JSON output |

## `messages`



```bash
bevor chat messages [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `chat_id` | text | Yes |  | Chat ID. |
| `--page-size, -n` | integer | No | 50 | Messages per page. |
| `--json` | boolean | No |  | JSON output |

## `new`

Create a chat thread and open the streaming terminal session.

```bash
bevor chat new [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--version` | text | No |  | Analysis version id (default: head of the configured analysis). |

## `resume`

Open the streaming session for an existing thread.

```bash
bevor chat resume [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `chat_id` | text | Yes |  | Thread id (`bevor chat list --json`, field id). |
