Findings for the configured analysis.

## `list`

Search findings across the team.

```bash
bevor finding list [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--page` | integer | No |  | Page number to use for resource that supports pagination |
| `--page-size` | integer | No |  | Page size to use for resource that supports pagination |
| `--order` | choice | No |  | How to order results when a resource supports pagination |
| `--order-by` | choice | No |  | What field to order results by when a resource supports pagination |
| `--type` | choice | No |  | Finding type. |
| `--level` | choice | No |  | Finding level. |
| `--acknowledged` | boolean | No |  | Filter by acknowledgement status. |
| `--operation` | choice | No |  | Staged draft operation. |
| `--created-by` | text | No |  | Created-by user id. |
| `--node` | text | No |  | Only findings tied to this graph node id. |
| `--json` | boolean | No |  | JSON output |

## `add`

Stage a new finding. ``--file`` is YAML; otherwise prompts interactively.

```bash
bevor finding add [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--version` | text | No |  | Version id to stage against (default: configured analysis head). |
| `--file, -f` | path | No |  | YAML file containing exactly one finding mapping. |
| `--interactive, -i` | boolean | No |  | Force interactive prompts. |
| `--type` | text | No |  |  |
| `--level` | choice | No |  |  |
| `--name` | text | No |  |  |
| `--explanation` | text | No |  |  |
| `--recommendation` | text | No |  |  |
| `--reference` | text | No |  |  |
| `--source` | text | No |  |  |
| `--node` | text | No |  |  |
| `--location` | text | No |  |  |
| `--uri` | text | No |  |  |
| `--start-line` | integer | No |  |  |
| `--start-column` | integer | No |  |  |
| `--end-line` | integer | No |  |  |
| `--end-column` | integer | No |  |  |
| `--char-offset` | integer | No |  |  |
| `--char-length` | integer | No |  |  |
| `--byte-offset` | integer | No |  |  |
| `--byte-length` | integer | No |  |  |
| `--fqn` | text | No |  |  |

## `edit`

Stage an edit (`--file` YAML or interactive matching current metadata).

```bash
bevor finding edit [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `finding_id` | text | Yes |  | Finding id to edit. |
| `--file, -f` | path | No |  | YAML with one mapping: ``type``, ``level``, ``name``, ``explanation``; optional ``recommendation`` / ``reference``. |
