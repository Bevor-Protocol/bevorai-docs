title: "team"

Manage team context.

## `select`

Set the active team. Uses the --team argument, or will prompt you to select from a list.

```bash
bevor team select [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--team` | text | No |  | Team id to select directly. |

## `list`

List teams you belong to.

```bash
bevor team list [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--json` | boolean | No |  | JSON output |
