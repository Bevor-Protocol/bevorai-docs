List, inspect, and upload code versions for the active project.

## `use`

Point `.bevor` at a code version.

```bash
bevor code use [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `code_id` | text | Yes |  | Code mapping id to use. |

## `list`

List code versions for the active project.

Examples:

  bevor code list
  bevor code list -j | jq '.[].id'

```bash
bevor code list [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--page` | integer | No |  | Page number to use for resource that supports pagination |
| `--page-size` | integer | No |  | Page size to use for resource that supports pagination |
| `--order` | choice | No |  | How to order results when a resource supports pagination |
| `--order-by` | choice | No |  | What field to order results by when a resource supports pagination |
| `--user` | text | No |  | Filter by user who created the code |
| `--project` | text | No |  | Project to filter by. Defaults to current configuration |
| `--network` | choice | No |  | Network to filter by |
| `--identifier` | text | No |  | Identifier (commit, hash, address) to filter by |
| `--status` | choice | No |  | Code status to filter by |
| `--json` | boolean | No |  | JSON output |
| `--all, -a` | boolean | No |  | List code versions for all projects in current team |

## `get`

Print details for the code version selected in ``.bevor`` config.

```bash
bevor code get [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--json` | boolean | No |  | JSON output |

## `push`

Upload a directory as a new code version. Updates local state to be the current code version.

```bash
bevor code push [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--path` | path | No |  | Source tree root (default: cwd). |
| `--no-wait` | boolean | No |  | Return immediately without waiting for the event stream to complete. |
| `--yes, -y` | boolean | No |  | Skip confirmation of action. |

## `node`

Inspect the code graph.

### `list`



```bash
bevor code node list [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--entrypoints` | boolean | No |  | Only show auditable entry-point functions. |
| `--file` | text | No |  | Filter to nodes in this file. |
| `--no-deps` | boolean | No |  | Filter to nodes under this directory prefix. |
| `--name` | text | No |  | Filter to nodes by name |
| `--node-type` | text | No |  | Filter to nodes by type |
| `--json` | boolean | No |  | JSON output |

### `get`



```bash
bevor code node get [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `node_id` | text | Yes |  | Node short id (or full wire id). |
| `--json` | boolean | No |  | JSON output |

### `content`

Examples:

```bash
bevor code node content [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `node_id` | text | Yes |  | Node short id (or full wire id). |

### `edges`



```bash

```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |

### `interactive`

Explore the graph from a node: get, source, optional call-chain (callable nodes only), and edges.

Forward jumps (from call-chain or edges) push the current node onto a stack; **Back** pops to
the previous node. get and source keep you on the current node.

```bash
bevor code node interactive [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `node_id` | text | Yes |  | Node to start from (short id or full id). |
