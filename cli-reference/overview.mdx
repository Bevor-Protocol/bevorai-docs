The Bevor CLI wraps the same functionality as the Python SDK and REST API for use
directly from your terminal — running analyses, checking status, and managing
projects without writing any code.

## Installation

```bash
pip install bevor-cli
```

## Usage

```bash
bevor --help
```

Each command group below has its own reference page listing its subcommands, options,
and defaults.
