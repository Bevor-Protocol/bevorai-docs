---
title: "sessions"
---

List and revoke CLI sessions.

## `list`

List active CLI sessions.

```bash
bevor sessions list [OPTIONS]
```

## `revoke`

Revoke a CLI session by id.

```bash
bevor sessions revoke [OPTIONS]
```

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `token_id` | text | Yes |  | CLI session id to revoke (from `bevor sessions`). |
