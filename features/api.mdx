# Build directly on the security graph

The API is the underlying interface for custom services, large-scale automation, and integrations that need direct control over Bevor resources.

## Intended use cases

- Create projects, code versions, and analyses from internal systems.
- Retrieve findings and attach validation or remediation workflows.
- Connect project security events to existing reporting and operations tooling.
- Build specialized products without creating a separate security record.
