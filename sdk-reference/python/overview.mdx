## Expanded Types

Certain resources support a `with_pagination` or `with_streaming` argument. If `True` is provided, the response extends the standard API response with added functionality, returning one of the SDK-only wrapper types below instead of the plain schema.

### `PaginatedResource`

<ResponseField name="results" type="list[T]">
The current page's items, in the same shape as the underlying (non-paginated) response.
</ResponseField>
<ResponseField name="has_more" type="bool">
Whether another page is available.
</ResponseField>
<ResponseField name="fetch_next" type="async method() -> None">
Fetch the next page and append its results to `results`.
</ResponseField>

### `EventResource`

<ResponseField name="data" type="T">
The underlying data of the requested resource
</ResponseField>
<ResponseField name="stream_completion" type="async iterator">
Method that opens an SSE connection to stream results. Events are typed and yielded. Once a success state is reached, the stream ends. As events come in, the data property is updated.
</ResponseField>
