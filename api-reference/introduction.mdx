Create custom security agents, tools, and integrations.

Developer-friendly API for building security automation into your agents, protocols, and chains.

## Welcome to Bevor API

Bevor provides a comprehensive API for integrating advanced security auditing capabilities into your development workflow. Whether you're building custom security agents, integrating into existing protocols, or creating specialized tools, our API enables you to leverage AI-powered security analysis at scale.

## Key Integration Types

### CLI and SDK
Use terminal and typed Python interfaces backed by the same API resources.

### CI/CD
Continuous reporting and team insights integrated into your development pipeline.

### API
Custom workflows and integrations for specialized use cases and protocol-specific needs.

### Dashboard
In-depth insights and automation through the Bevor web dashboard interface.

### Bevor Skills
Help coding agents use the CLI and SDK through a bounded, graph-aware workflow.

### Multi-Agent Triaging (A2A)
Risk profiling and orchestration for complex security scenarios.

## Authentication

At launch, API endpoints will use Bearer tokens in the Authorization header:

```bash
Authorization: Bearer YOUR_API_KEY
```

API-key creation will be documented when public access opens.
