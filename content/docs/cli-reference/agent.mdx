Audit agent workflow shorthands.

## `setup`

Assumes user has ran `bevor init`. After that, running the setup will sync code, generate an
analysis, and set the original scopes to first-party only.

```bash
bevor agent setup [OPTIONS]
```

## `materialize`

Write each scope to ``.bevor/analyses/{analysis_id}/{scope_short_id}.raw.md`` (source + server call-chain text).

Call chain uses the graph API ``response_type=text``; used to feed skills without re-running graph commands.

```bash
bevor agent materialize [OPTIONS]
```
