# Typed clients for one security graph

The SDKs wrap the same projects, code versions, analyses, and findings exposed by the API, with typed resources and pagination handled for you. Reach for an SDK when you are embedding Bevor into internal tooling or custom agents, and the API when you need control at the HTTP boundary.

Python is the first supported language. Additional languages will be documented here as they ship.
