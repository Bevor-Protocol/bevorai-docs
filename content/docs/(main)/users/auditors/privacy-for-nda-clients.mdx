Use privacy-preserving features for sensitive client engagements.

<Warning>
  Bevor is coming soon, and its privacy and deployment controls are not finalized. Do not submit NDA-bound code based on these preview docs.
</Warning>

## On-premise deployment

Regulated and air-gapped deployment options are under consideration for enterprise use cases. Contact [contact@bevor.io](mailto:contact@bevor.io) to discuss requirements.

## Controls

- Local-only analysis options
- Redaction of secrets and identifiers
- Granular data retention controls
- Access controls and audit logs

## Recommendations

1. Confirm deployment and retention terms before submitting code
2. Restrict data sharing and telemetry
3. Use redaction for reports and exports
4. Periodically review access logs
