### What is Bevor?

Bevor is AI-native security infrastructure with persistent context. It connects code, analyses, findings, remediations, and contributors through one project graph.

### Is Bevor publicly available?

No. The platform, Dashboard, CLI, SDK, API, CI/CD integration, and Bevor Skills are all coming soon. Commands and interfaces in these docs are previews and should not be run yet.

### Why use a graph instead of only a code diff?

A diff identifies changed lines. The Bevor graph connects code entities through calls, reads, writes, inheritance, guards, and other semantic relationships, revealing downstream code that a small change can affect.

See [Graph-native Analysis](/features/graph-native-analysis) for an interactive explanation.

### Which integrations are planned?

Bevor is designed to work through the Dashboard, CLI, SDK, API, and CI/CD. Bevor Skills will help Claude, Codex, and compatible coding agents use the CLI and SDK effectively.

### Does Bevor provide post-deployment monitoring?

Post-deployment monitoring is not a core Bevor product surface. A team could build a specialized monitoring solution on the SDK or API for its own requirements.

### How should teams interpret a rising finding count?

Finding counts often rise when a team adds stronger tools and reviewers. The important trajectory is whether validated outstanding findings trend toward zero while verified remediations trend upward. See [Project Analytics](/features/project-analytics).

### Can Bevor be used for confidential projects?

Privacy and deployment options are still being defined for launch. Do not send confidential or NDA-bound source code based on these preview docs.

### What languages will Bevor support?

The current product preview focuses on Solidity. Additional language support will be documented when confirmed.
